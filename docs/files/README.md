# Ordner `docs/files/`

Exportierte Einzelnotizen und Code-Schnipsel aus der Entwicklungsphase
(vorwiegend aus Notion/Word kopierte Arbeitsmaterialien). Die Dateien
dienen als Referenzmaterial für die Thesis-Ausarbeitung.

## Bestand

| Datei | Inhalt |
|---|---|
| `Aufgabe.txt`, `Aufgabe_Fehlerbeschreibung.csv` | Beispiel-Aufgabe und typische Fehlklassifikationen |
| `json_schema.txt`, `aufgaben_json.txt` | Entwürfe des Task-Formats / JSON-Schemas |
| `Fast API app.txt`, `Dateistruktur Prototyp.txt` | frühe App-Version und geplante Struktur |
| `Bsp für erzeugtes Prompt.txt` | vollständig generierter Beispiel-Prompt (Kontextsteuerung) |
| `moodlelink.txt`, `FeedbackLink.txt`, `URL encoding.txt`, `Question variable.txt` | Moodle-Anbindung: Feedback-Link, URL-Encoding, STACK-Variablen |
| `TutorDaten.txt` | Datenstruktur für den Tutor (Chat/Session) |
| `requirements.txt` | dependency-Notiz |

## Hinweise

- Diese Notizen dokumentieren Zwischenstände — verbindlich sind ausschließlich Code, `AGENTS.md` und die READMEs der `code/`-Unterordner.
- Historische Inhalte (z. B. `OLLAMA_*`-Konfiguration) zeigen den Stand vor der SAIA-Migration.
